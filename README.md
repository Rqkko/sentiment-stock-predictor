# How to Contribute
1. Create new branch from `main`
2. Create a `pull request` once implementation is finished
3. Wait for reviewer to approve/disapprove your request
4. If disapprove, check the comments and modify the code accordingly

# How to Commit

Run the following command to create .py file to from .ipynb

```
jupytext --set-formats ipynb,py notebooks/eda_data_download.ipynb
```

Then proceeds to commit normally `to your branch`
